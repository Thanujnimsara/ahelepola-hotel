Firebase Integration Guide

Follow these quick steps to connect your Firebase Project to this website.

1

Create a Firebase Project

Go to the Firebase Console and click "Add project". Name it e.g. ahelepola-hotel.

2

Enable Email / Password Authentication

In your Firebase project sidebar, click Build > Authentication > Get Started. Under the Sign-in method tab, enable Email/Password and click Save.

Next, go to the Users tab and click "Add user". Enter your desired admin email (e.g. admin@ehelepolahotel.lk) and a strong password. This is what you will use to log into this admin panel!

3

Create Cloud Firestore Database

In the sidebar, click Build > Firestore Database > Create database. Choose a nearby region (e.g. asia-south1 - Mumbai/Singapore) and start in Production mode or Test mode.

rules_version = '2'; service cloud.firestore { match /databases/{database}/documents { // Anyone can read hotel info & rooms on the public website: match /{document=**} { allow read: if true; allow write: if request.auth != null; // Only logged in admins can write! } } }
4

Insert Your Configuration Keys

In Firebase Console, click the Project settings gear (⚙️) > General > scroll to "Your apps" > click the Web (</>) icon. Copy the firebaseConfig object and paste it into firebase-config.js.
